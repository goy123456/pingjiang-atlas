# Pingjiang Atlas — static map demonstration

Interactive modern map and historical comparison. No Python server, AI service, API keys, participant data, or research logs are included.

Enable GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

OSM geometry © OpenStreetMap contributors, ODbL. Source metadata accompanies the map and photographs. Third-party materials are not relicensed by this project. The historical photograph lacking public reuse permission is excluded.
